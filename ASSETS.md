# Assets and licenses

AgentVille ships **no third-party images, sprites, tilesets or sounds**. Everything you see in the world is drawn by code when the app starts.

## Original art (MIT, same as the code)

| What | Where | How |
| --- | --- | --- |
| Tileset (grass, flowers, forest, paths, wood floor, walls, windows, bricks, pond with shores) | `src/renderer/src/game/art/tiles.ts` | Small procedural painters with a fixed random seed |
| Characters (16×24, 4 directions, walk, typing and dozing frames, 3 hair styles + cap) | `src/renderer/src/game/art/characterTemplates.ts`, `characters.ts` | String templates recolored with per-agent palettes |
| Props (desks and monitor screens, trees, bushes, plants, sofa, rug, bookshelf, water cooler, coffee counter, whiteboard, clock, bench, lamp post) | `src/renderer/src/game/art/props.ts` | Drawn with rectangles and pixel ellipses |
| Bubbles, zZz, E key | `src/renderer/src/game/art/icons.ts` | String templates |
| Palette | `src/renderer/src/game/art/palette.ts` | Hand-picked |
| App icon | `build/icon.png`, `resources/icon.png` | Generated by `scripts/generate-icon.mjs` from the character templates (`npm run icon`, Node 22.6+) |
| UI icons | `src/renderer/src/ui/Icon.tsx` | Hand-written SVG paths |

All of it was created for AgentVille and is not based on any existing game, franchise or brand.
